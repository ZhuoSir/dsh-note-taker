> 本版为首次发布：DSH 插件「会记」，录音 → 转写 → 纪要，本地与云端双引擎，产物落会话工作区

## 一句话

装上会记，开会时点一下录音，停录后自动出转写，再让会话把转写整理成纪要；
全程可离线（本机 faster-whisper），也可以走阿里云百炼（更快、带说话人分离），还能边录边出字幕。

## 新增能力

### 录音与转写

- 会话卡片一键录音/停录；默认 16kHz 单声道 WAV，落 `~/.dsh/note-taker/recordings/`
- **本地转写**：本机 faster-whisper（默认 `small` 档；`tiny` 档中文不可用，见 README）
- **云端转写**：阿里云百炼 `qwen-audio-3.1-asr-flash`，支持说话人分离（S1/S2…）、术语热词、长音频分片
- 引擎可切：设置页 `配置` 里选本机/云端；优先级 `config.json` > 环境变量 > 缺省
- **流式识别**（可选，默认关）：开启后录音期间持续推流，卡片上实时出字幕，停录约 1 秒内定稿；
  连不上或中途断线自动降级回整段识别，音频不丢

### 产物与交接

- 转写与纪要写成单个 md（`meetings/YYYYMMDD-HHmm-xxxx.md`）+ 同目录 `.json` 侧车
- 产物写入当前会话的工作区（工作区模式），不再是数据目录里的一份孤立文件
- 「交给会话生成纪要」：把产物路径交给当前会话，由 agent 读文件写纪要（不再塞长文本进上下文）
- `meeting_import` 工具：导入已有音频（支持无扩展名/容器嗅探），可选顺带转写

### 页面与日志

- 设置页「会记」：配置（引擎/模型/Key/说话人分离/流式开关）+ 历史纪要（只读）
- 会话输入框右侧「会记」快捷入口
- 关键环节都有日志（录音启停、转写调用、流式会话、产物落盘），日志不含 API Key

### 桌面版安装

- `npm run install:desktop` 幂等装进 Electron 的 `desktop` profile（装前备份、失败回滚）
- `npm run verify:desktop` 五项自检 + Key 来源 + 兼容告警
- `npm run uninstall:desktop` 干净摘除，不动录音与转写数据

## 已知限制

- 流式识别依赖云端实时接口；离线或密钥失效时无实时字幕（自动降级，功能不中断）
- 本地转写的档位取舍：`tiny` 中文不可用；`small` 为默认；更高档位更慢
- 麦克风录音需要本机 Python 与依赖齐备；缺失时插件只报告不自修
- 桌面版进程探测仅 Windows；其它平台安装器恒判「未运行」（不阻断）
- 桌面版兼容声明目前只列 `0.1.7-rc.1`/`rc.2`，其它版本只告警不阻断（BL-07 跟进）
- 线上会议抓「对方声音」（loopback）本版未做（BL-03）；长会议分块未做（BL-04）
