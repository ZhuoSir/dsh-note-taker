# 变更请求 CR-01：卡片不得遮挡输入区，撤销跨会话的展开记忆

## §S Specify（变更意图 → R 增/改/删）

**触发**：陈卓 于 2026-11-11 13:29 真机测试后提出，原话：

> 「我点击会记，再收起来，是可以点击输入框的；但是录制中和录制结束后不能操作，我将画面缩小然后再大化，恢复了」

补充现象（同日 13:29）：

> 「输入框在，但是无法输入，光标无法进入」

**事实认定（已实测）**：

- 卡片收起时输入框可用；卡片展开时输入框无法获得焦点 → 遮挡物就是展开的卡片
- 窗口缩放后恢复 → 遮挡与输入区的几何位置相关，重排后错开
- `styles.panel` 的 `bottom: calc(100% + 8px)` 是相对 16px 高的入口而非整行输入区计算，
  卡片下沿会压进输入行
- 本次新增的「开合记忆」让展开态跨会话常开，把该缺陷放大成「所有会话都打不了字」

### 新增 R

#### R-10 卡片不得遮挡输入区

WHEN 会记卡片处于展开状态（含录制中与录制结束后），系统 SHALL 保证会话输入框可点击、可获得光标、可输入文字；
卡片 SHALL NOT 与输入区在几何上重叠。

验收场景: GIVEN 卡片展开并正在录音 WHEN 点击输入框并打字 THEN 光标进入、文字可见、可发送消息

### 修改 R

- R-05 旧：「WHEN 用户收起卡片，系统 SHALL 记住该选择，使用户下次进入会话时卡片保持收起状态」
  → 新：「卡片 SHALL 默认收起；开合状态 SHALL NOT 跨会话或跨会话重载持久化，
  仅当用户本次点击入口才展开；收起后入口 SHALL 常驻可见」
  （原句全文见 `git show HEAD~:specs/20261112_meeting-trigger/requirements.md`）

### 受影响既有 R 清单（必答）

| R | 是否受影响 | 说明 |
|---|---|---|
| R-01 入口构成 | 否 | 仍是圆点 + 文字，样式不变 |
| R-02 状态色彩 | 否 | 不变 |
| R-03 录制计时 | 否 | 不变 |
| R-04 打开与收起 | 是（措辞） | 收起方式不变（点入口/点外部/Esc），但不再持久化 |
| R-06 可访问性 | 否 | `aria-expanded` 仍跟随开合 |
| R-07 功能不回归 | 是（加强） | 新增「录制中必须能继续对话」的验收 |
| R-08 主题安全 | 否 | 不变 |
| R-09 可测 | 否 | 不变 |

**交叉检查**：R-10 与 R-04 是否冲突？不冲突——R-04 管「怎么开怎么关」，R-10 管「开着的时候不许挡住输入」。
R-10 与 R-05（新）是否冲突？不冲突——默认收起使重叠窗口更少，但不替代几何修正（用户明确要求「录制中也要能对话」）。

### Non-goals（本次不跟着做）

- 不解决「录音跨会话丢失 / 停止入口只在一个会话」（另立 spec `20261112_recording-decouple`，BUG-02/BUG-04）
- 不改卡片内部的信息密度与字段
- 不做卡片拖拽、不改成侧边抽屉

### 为何不能另立新 spec

这是对**同一个入口组件**同一段样式的修正；另立 spec 会产生两份互相矛盾的「会记入口」规格，
后续任何改动都要同时改两处——正是技能里禁止的重复真相源。

### 假设（不纠正即按此执行）

1. 「遮挡」按几何重叠理解（卡片树与输入区像素相交即为遮挡），不靠 `pointer-events: none` 糊过去
2. 卡片保留在 `conversation.input.right` 插槽内相对定位，只把锚点从「入口高度」改为「输入行高度」
3. 「跨会话记忆」整条撤掉，不保留「记住上次是开着」的半个实现

### 被拒绝的替代方案

| 方案 | 拒绝原因 |
|---|---|
| 用 `pointer-events: none` 让卡片不吃点击 | 治不了根：卡片仍压在输入区上方，用户看不见自己在打什么；且 R-10 要求「不重叠」 |
| 录制时自动收起卡片 | 掩盖问题：录制中用户仍需要看字幕，且录制结束后展开再次遮挡 |
| 卡片改 portal 到窗口右下角 | 引入与宿主布局的耦合（滚动、缩放、多窗口），本次只改锚点即可满足 R-10；如仍不够，后续再立 |
| 保留「记住上次展开」但跨会话重置 | 半个实现比没有更难理解，且用户要的是默认收起 |
| 另立新 spec | 见 §S「为何不能另立新 spec」 |

### 风险与规避

| 风险 | 规避 |
|---|---|
| 入口撑满行高后，圆点与文字的垂直位置偏移 | 用 flex 居中对齐，保持视觉原位；真机复验 |
| 卡片在窄窗口下宽度 380 超界 | 加 `maxWidth: min(380px, calc(100vw - 24px))` |
| 去掉记忆后用户抱怨「每次都要点开」 | 这是用户明确要求（R-05 新）；若日后要记忆，另立 CR |
