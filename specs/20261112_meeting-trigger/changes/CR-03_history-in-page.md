# CR-03 历史纪要搬到会记页面

## §S 需求变更

### 触发

用户 2026-11-12 要求（原话）：

> 设置-会记里的 历史纪要，挪到外面会记标签的页面里

### 判断

现状是「配置 + 历史纪要」都塞在 **设置 → 会记**，而用户实际操作时人在 **侧栏会记页面**：
录完、要找上一场，得先跳设置、再翻标签，路径绕。

`R-07` 与 `S-06` 当初写的是「设置页 SHALL NOT 受影响 / 不改设置页（配置 + 历史纪要）」——
这条约束正好与现在的诉求冲突，所以按规则走 CR，不在施工中擅自改需求。

另有一处体验缺口与本次一并解决：设置页的历史列表只列 `hasMinutes` 的会议，
**没有纪要的会议根本不出现在列表里**——这正是用户 2026-11-12 反馈「刚录完的找不到」的场景之一。

### 条款变更

| 条款 | 处置 | 说明 |
|---|---|---|
| R-07 功能不回归 | 改 | 由「设置页 SHALL NOT 受影响」改为「设置页只留配置；历史纪要归会记页面，设置页不再提供历史列表」 |
| R-13 会记页面 | 改 | 页面内容由「录音控制 / 实时字幕 / 当前会议 / 转写确认 / 历史入口」扩为「…/ 历史纪要」——历史不再是跳转入口，而是页面内的实体区块 |
| S-06（验收） | 改 | 由「不改设置页（配置 + 历史纪要）」改为「设置页只剩配置；历史纪要在会记页可用」 |
| R-15 历史纪要列表（新增） | 增 | 会记页面 SHALL 列出会议（默认最近 20 场，可展开更多），每行显示开始时间、时长、状态；点击展开正文 |

### 边界（本次不做）

- 不做搜索、筛选、批量删除、导出；
- 不做「按工作区/按会话」分组；
- 纪要生成仍走「转写 → 交给会话」，本次不新增生成按钮。

## §P 方案

### 页面结构（会记页，`QuickPanel({ page: true })`）

```
[录音控制 / 实时字幕 / 转写确认]   ← 已有
────────────────────────────────
历史纪要（N）
  11-12 13:09   1:04:35   已生成纪要   ← 点击展开
  11-11 17:20   0:52      仅转写
  11-11 14:12   0:50      识别失败
  [展开更多]
────────────────────────────────
展开行正文：优先纪要（`## 纪要` 段），无纪要则显示转写，两者都没有则说明原因
```

### 数据来源（复用，不新增接口）

- 列表：`GET /note-taker/list`（已有 `api.list`），前端按 `startedAt` 倒序取前 N
- 正文：`GET /note-taker/detail`（已有 `api.detail`），返回 `transcript` / `minutes` 两段

### 实现要点

1. 新增 `src/client/HistoryList.jsx`：纯展示 + `onOpen(id)` 回调，行数据由 `toListRows` 产出，**复用** 现有行扁平化逻辑与 `paginateTranscript` 分页；
2. `QuickPanel` 页面模式在确认区之后渲染 `HistoryList`，展开行复用「`pre` + 展开剩余 N 行」样式；
3. `SettingsPage`：删除 `tab === 'minutes'` 的表格与正文卡片、删除 `历史纪要（N）` 标签、删除相关 state（`meetings / openedId / minutesText / showAll`）与 `loadMinutes / openMinutes / minutesRows`；
4. 设置页说明文案由「配置与历史纪要；录音与生成纪要在…」改为「只放配置；录音、历史纪要与生成纪要在侧栏「会记」页面」；
5. 页面历史列表不再用 `hasMinutes` 过滤——**所有会议都列**，用状态徽标区分「已生成纪要 / 仅转写 / 识别失败」，这样没出纪要的会议也不会「找不到」。

### 兼容与回退

- 只动客户端渲染，不动任何路由与服务端契约 → 回退只需还原 `lib/client.js`；
- 设置页删除的 state 若有测试引用（`page-render.test.js` 的 `0..9` 注入序），需同步更新测试注入表。

## §T 测试与验收

| 用例 | 预期 |
|---|---|
| 会记页列出会议 | 至少出现最近一场；每行有时间与状态徽标 |
| 点行展开 | 有纪要显示纪要；无纪要显示转写；都没有给出原因 |
| 分页 | 长文本显示「展开剩余 N 行」，点开后全文 |
| 设置页 | 不再有「历史纪要」标签与表格；配置项照常可改可存 |
| 空数据 | 没有任何会议时显示「还没有会议」，不崩 |
