# 需求规格：meeting-page（会记页面）

## 背景与目标

前两个 spec 把「录音 → 转写（本地/云端）→ 纪要」做通了，但**只能靠在会话里喊工具**：
看不到历史会议，也不知道哪次转写跑完了；录音和导入没有任何按钮，纪要生成后要自己去翻文件。

目标：在 DSH 里给会记一个**真正可用的界面**——设置区一页看全部会议、点开看转写与纪要、
能发起转写/纪要/录音；会话输入框旁再放一个快捷入口，开会时不用离开对话。

成功长什么样：打开「会记」页看到会议列表与状态；点一份录音 → 选云端 → 看到进度 → 转写完成 →
点「生成纪要」→ 正文出现在详情里；整个过程不用碰命令行。

## 需求条款

### R-01 页面可打开，列表可用

WHEN 用户在 DSH 设置区打开「会记」页，
系统 SHALL 展示会议列表：时间、标签、时长、引擎（本地/云端）、录音/转写/纪要三个状态。

WHEN 没有任何会议，
系统 SHALL 展示空态与下一步引导（录音 / 导入音频）。

边界：列表默认按开始时间倒序，最多 100 条；状态必须与实际一致（不能靠前端猜）。

#### 验收场景

- **GIVEN** 数据目录有 3 场会议
  **WHEN** 打开页面
  **THEN** 3 行按时间倒序，状态列与 `meetings.json` 一致
- **GIVEN** 数据目录为空
  **WHEN** 打开页面
  **THEN** 显示空态与两个引导按钮

### R-02 数据一律经宿主接口

WHEN 页面需要数据，
系统 SHALL 通过宿主侧 HTTP 接口获取（列表、详情、动作），**前端不得直读磁盘**。

边界：接口失败时页面 SHALL 显示可读错误与「重试」，不得白屏或抛未捕获异常。

#### 验收场景

- **GIVEN** 宿主接口返回 500
  **WHEN** 打开页面
  **THEN** 页面显示错误说明与重试按钮
- **GIVEN** 一次正常请求
  **WHEN** 检查响应
  **THEN** 返回结构化 JSON（含 `ok` 字段），不返回 HTML

### R-03 详情：元信息 + 转写 + 纪要

WHEN 用户选中列表中的一场会议，
系统 SHALL 展示：标签、起止时间、时长、音频路径、引擎、状态、统计（段数/字数）；
以及转写正文与纪要正文（存在时才显示对应区块）。

边界：转写或纪要缺失时显示「尚未生成」而不是空白；正文过长时页面可滚动、不卡死（47 分钟约 550 段）。

#### 验收场景

- **GIVEN** 一场已转写未出纪要的会议
  **WHEN** 点开详情
  **THEN** 显示转写全文与「尚未生成纪要」提示
- **GIVEN** 550 段的转写
  **WHEN** 渲染详情
  **THEN** 首屏渲染在 1 秒内完成（正文按需展开或虚拟滚动）

### R-04 页面上的动作

WHEN 用户在页面上触发动作，
系统 SHALL 支持：开始/停止录音、导入已有音频、转写（可选引擎）、生成纪要、重新生成纪要。

WHEN 动作执行中，
系统 SHALL 在该会议行回显状态（进行中 / 完成 / 失败），失败时展示原因。

边界：云端引擎必须在动作前后都能看到「音频将上传阿里云百炼」的提示；录音依赖缺失时按钮禁用并说明原因。

#### 验收场景

- **GIVEN** 一场只有录音没有转写的会议
  **WHEN** 点击「云端转写」
  **THEN** 行状态变为进行中，完成后变为完成且详情出现正文
- **GIVEN** 未配置 `DASHSCOPE_API_KEY`
  **WHEN** 点击「云端转写」
  **THEN** 提示缺少密钥与配置方法，不发生请求

### R-05 会话输入框旁快捷入口

WHEN 用户在会话输入框旁点击会记按钮，
系统 SHALL 弹出轻量面板，可：开始/停止录音、查看最近 3 场会议状态、跳转到会记页。

边界：面板不得遮挡输入框；录音中按钮显示计时；停止后会议自动出现在列表首位。

#### 验收场景

- **GIVEN** 会话页
  **WHEN** 点击会记按钮
  **THEN** 弹出面板且不遮挡输入框
- **GIVEN** 录音进行中
  **WHEN** 观察按钮
  **THEN** 显示计时与「停止」态

### R-06 进度可见

WHEN 一次转写或纪要任务在跑，
系统 SHALL 让用户在页面上看到「进行中」与已用时间，刷新页面后仍能看到（状态来自服务端而非内存）。

边界：不得出现「前端显示进行中但服务端已失败」的长期不一致（超过一个轮询周期即纠正）。

#### 验收场景

- **GIVEN** 一次 47 分钟录音正在云端转写
  **WHEN** 刷新页面
  **THEN** 该行仍显示进行中与已用时间
- **GIVEN** 任务在后台失败
  **WHEN** 下一次轮询
  **THEN** 行状态变为失败并显示原因

### R-07 隐私与本地边界

WHERE 页面与接口，
系统 SHALL 只在本机可用（监听回环地址），不接受来自非本机的请求。

WHEN 用户选择云端引擎，
系统 SHALL 在界面上明确提示「音频将上传阿里云百炼」，首次选择时要求二次确认。

边界：接口只允许访问数据目录内的文件，不得接受任意路径读写。

#### 验收场景

- **GIVEN** 首次点击「云端转写」
  **WHEN** 弹出确认
  **THEN** 文案含「上传阿里云百炼」；取消则不发起请求
- **GIVEN** 请求带 `../../etc/passwd` 之类路径
  **WHEN** 接口收到
  **THEN** 返回参数错误，不读取该路径

### R-08 前端可构建、可回归

WHEN 修改前端源码，
系统 SHALL 能用一条命令重建 `lib/client.js`（esbuild，React 与宿主包走 external）。

WHEN 执行 `npm run verify`，
系统 SHALL 校验前端产物存在且与源码一致（重建无 diff），并跑页面纯逻辑单测。

边界：不得把构建产物手工编辑后提交而无法复现。

#### 验收场景

- **GIVEN** 干净仓库
  **WHEN** `npm run build:client && npm run verify`
  **THEN** 产物存在、重建无 diff、单测通过
- **GIVEN** 人为改坏格式化函数
  **WHEN** verify
  **THEN** 对应用例失败并指出断言

### R-09 纯逻辑单测

WHEN 执行单测，
系统 SHALL 覆盖页面纯逻辑：状态映射、时长格式化、列表排序与过滤、接口错误到用户文案的映射、
云端隐私提示的触发条件。

边界：不得只断言「组件能渲染」而不验行为。

#### 验收场景

- **GIVEN** 一条 `transcribe=failed` + `errors.transcribe` 有值的会议
  **WHEN** 映射为展示态
  **THEN** 返回「失败」与原因文案
- **GIVEN** 时长 2826 秒
  **WHEN** 格式化
  **THEN** 显示 `47:06`

## Non-goals（范围外）

- 多用户、权限、远程访问（本机单人使用）
- 会议删除/归档/重命名管理
- 导出 Word / 分享链接
- 实时字幕（边说边出）
- 移动端与窄屏适配
- 说话人重命名（云端 S0/S1 只展示不改写）

## 我正在做的假设

1. 页面挂在 **`settings.section` 插槽**（已装插件 `dsh-sessions-manager` 实证该插槽可用且可承载完整页面）。
2. 快捷入口挂 **`conversation.input.right`**（同插件生态中已见使用）。
3. 宿主接口用 `ctx.webServer.register({ kind:'exact', path })` 注册精确路径；
   靠查询串传参（避免依赖未知的路由参数能力）。
4. 前端用 **React 18 + esbuild**，`react` 与 `@deepseek-ai/*` 打成 external，产物 `lib/client.js`；
   `package.json` 增加 `dsh.client` 声明与 `./client` 导出。
5. 进度用 **轮询**（2 秒），不做 SSE/WebSocket。
6. 页面与接口都只在 `127.0.0.1` 上可用。

现在纠正，否则按此执行。
