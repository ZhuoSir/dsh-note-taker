  验收标准: 五类用例全绿；模块不 import React

## 2. 宿主路由

- [x] T-04 六条 HTTP 路由
  关联: R-02, R-04, R-06, R-07
  依赖: 无
  验证方式: `node --test tests/routes.test.js` —— 用假 req/res 直接调 handler：
  list 默认 20 / limit 校验；detail 缺转写时字段为 null 不是 500；health 缺 key 时 `cloud.configured=false`；
  transcribe 立即返回 `accepted` 且校验 engine 枚举；minutes 转发 force；record start 冲突返回 `E_STATE`；
  路径穿越式 `id`（含 `../`）被拒
  日志断言: 每个请求出现「路由请求」（method/path/query 摘要）与「路由响应」（status/耗时）；非法入参出现 WARN「非法入参」含字段名；**日志中检索不到转写正文与密钥**
  验收标准: 八类用例全绿；全部响应为 JSON 信封
